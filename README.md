
# TDS GA3 — Q7: Face Morph Video

## Project Overview
This project contains a short video created for Question 7 of the Tools in Data Science (TDS) GA3 assignment. The video demonstrates a transition that morphs the first face into the second.

## Video
The video file is [`morph.mp4`](./morph.mp4).

## Assignment Requirements
- Create a video that morphs the first face smoothly into the second.
- Make the transition as natural and seamless as possible.
- Keep the video smaller than 100,000 bytes.
- Provide a public HTTPS URL that links directly to the video.
- Ensure the video is accessible through a browser for offline evaluation.
